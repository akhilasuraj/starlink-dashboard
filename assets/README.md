# App icon

`app-icon.png` is the original generated application identity, used by the desktop window and navigation. `build/icon.png` is the 512px packaging image; `build/icon.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256px Windows variants. Conversion preserves the generated transparency. Tray status icons remain separate so collection/service health stays distinguishable.

Generated using the built-in imagegen tool on 2026-09-28. The design is an original dish-and-signal identity, distinct from Starlink's official orbital logo. No downloaded storefront imagery is shipped in the app.

## Generation prompt

Use case: logo-brand. Asset type: production Windows desktop application icon for a local Starlink monitoring and history dashboard. Create one polished original icon, no text. A bold, exceptionally simple white silhouette of a modern flat rectangular satellite internet terminal tilted upward on a short pedestal, with one clean sweeping signal arc above it. The silhouette must be instantly legible at 16–32 pixels, with thick confident shapes, generous separation and no tiny details. Center on a solid black rounded-square tile with subtle dimensional edge lighting, slightly inset from the canvas. Palette: pure black, soft white, restrained cool silver; monochrome. Crisp precision-engineered appearance consistent with the current minimal black Starlink mobile interface, but an original monitoring app identity, not the official Starlink orbital logo or wordmark. Single icon only, straight-on orthographic presentation, no scene, no mockup, no stars, no lettering, no watermark, no shadow outside tile. Transparent background outside the rounded-square tile; preserve real alpha. Square composition, tile fills about90% of canvas, symbol fills about65% of tile.
