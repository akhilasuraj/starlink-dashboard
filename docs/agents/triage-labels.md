# Triage labels

The engineering skills use five canonical triage roles. Their GitHub label names for this repository are:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer needs to evaluate the issue. |
| Needs information | `needs-info` | The reporter needs to provide more information. |
| Ready for agent | `ready-for-agent` | The work is fully specified and can be picked up without more human context. |
| Ready for human | `ready-for-human` | The work needs human implementation or judgment. |
| Won't fix | `wontfix` | The issue will not be actioned. |

Use the label in the second column when a skill refers to one of these roles. These labels describe an issue's current triage state; replace the previous state label when the state changes.
