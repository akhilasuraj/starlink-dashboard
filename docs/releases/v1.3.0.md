# Starlink Dashboard 1.3.0 — candidate

## Updates inside the app

Devices now includes App updates. Installed Windows copies check automatically on launch and every six hours. When a newer GitHub version is available, choose Download update, then Restart and install. The collector stops before installation; the app restarts afterward. Closing to tray, ordinary Quit, and Windows logoff do not install downloaded updates.

Downloads show progress and verify SHA-512 against release metadata. Errors remain retryable while monitoring continues. The repository’s GitHub prereleases are included; downgrades are disabled. History and the opt-in startup setting are preserved.

**Version 1.2.0 and earlier need one manual installation of this release to receive the updater.** After the manual bootstrap, check the start-on-sign-in setting: the historical uninstaller may clear it. Later versions can be installed from the app and retain that preference. The Windows installer may display its normal wizard.

## Verification and publication

50 behavioral, transport and release-gate tests pass, including asynchronous installer failure and retry using the actual pinned updater methods. Actual Electron fixture previews passed at wide and compact sizes, with available/downloaded/error/current states and download progress. These fixtures execute no installer and make no hardware calls. Final publication additionally requires successful hosted offline installation, update metadata bound to the exact installer, and a two-version installed upgrade on a disposable Windows runner. The upgrade test uses a lower-version build of current source and test-only silent installation; it does not claim historical 1.2.0 can update itself.

The owner explicitly requested **1.3.0 as the latest stable release**. [Version-bound approval](../release-approval.json) records that request and the existing hardware acceptance with acknowledged limitations. The earlier Standard 4 / Gen 3 live hardware evidence remains partial and scoped to its original runtime/source; stable classification does not imply a new live hardware pass. Offline installation, installed upgrade and exact artifact checks remain mandatory.

The current Windows installer is unsigned; checksum verification is integrity checking, not cryptographic publisher authentication. The interactive installer wizard is not exercised by the unattended hosted upgrade check. See [release verification](../release-verification.md) and [implementation](../auto-update.md).

A fresh read-only live check of the exact extracted CI-tested 1.3.0 bundle passed: three history ranges, observed ping success/API agreement, chart units, safe owned-collector recovery, restart/history retention and unchanged startup entries. [Evidence](../validation/auto-update-live/desktop-live.json). The test used an isolated profile and did not install over the owner’s running app or induce a service outage.
