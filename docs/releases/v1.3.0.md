# Starlink Dashboard 1.3.0 — candidate

## Updates inside the app

Devices now includes App updates. Installed Windows copies check automatically on launch and every six hours. When a newer GitHub version is available, choose Download update, then Restart and install. The collector stops before installation; the app restarts afterward. Closing to tray, ordinary Quit, and Windows logoff do not install downloaded updates.

Downloads show progress and verify SHA-512 against release metadata. Errors remain retryable while monitoring continues. The repository’s GitHub prereleases are included; downgrades are disabled. History and the opt-in startup setting are preserved.

**Version 1.2.0 and earlier need one manual installation of this release to receive the updater.** After the manual bootstrap, check the start-on-sign-in setting: the historical uninstaller may clear it. Later versions can be installed from the app and retain that preference. The Windows installer may display its normal wizard.

## Verification and publication

48 behavioral tests passed before adding the final installed-upgrade gate. Actual Electron fixture previews passed at wide and compact sizes, with available/downloaded/error/current states and download progress. These fixtures execute no installer and make no hardware calls. Final publication additionally requires successful hosted offline installation, update metadata bound to the exact installer, and a two-version installed upgrade on a disposable Windows runner. The upgrade test uses a lower-version build of current source and test-only silent installation; it does not claim historical 1.2.0 can update itself.

The earlier Standard 4 / Gen 3 live hardware evidence remains scoped to its original runtime/source. This candidate inherits its partial validation and must remain a prerelease unless the hardware record is updated and accepted. The current Windows installer is unsigned; checksum verification is integrity checking, not cryptographic publisher authentication. See [release verification](../release-verification.md) and [implementation](../auto-update.md).
