# Starlink Dashboard v1.2.0

## Changes

- Redesigned Overview, Statistics, Obstructions, Devices and Collector logs from current official Starlink mobile UI references: dark surfaces, compact cards, large readings and restrained charts.
- Persistent desktop navigation adapts to compact windows, with keyboard navigation, visible focus and selected states.
- New original dish-and-signal icon for the window, navigation, installer and Windows shortcuts.
- Existing observed history, source/freshness details, collection gaps and reported-outage semantics are preserved.

## Installation

Windows 10/11 x64. Download `Starlink.Dashboard.Setup.1.2.0.exe` from this release and run it. The installer bundles the collector and Python runtime; no separate Python install is needed. Start on sign-in remains opt-in. Closing the window keeps collection in the tray; choose Quit to stop it.

## Verification and limitations

The release workflow runs fixture/API and desktop behavioral tests, builds the installer, checks the packaged collector/app, and installs the exact artifact offline on a disposable Windows runner. Publication is blocked unless those checks pass. UI evidence additionally includes 20 real Electron fixture screenshots at 1120×800 and 600×750, all five views, keyboard activation, range switching, error/unavailable cases, long identifiers, chart sizing and normal cleanup.

Historical live evidence covers the owner's Standard 4 dish with Gen 3 Starlink router, without bypass. It was collected for the earlier revival version, not this new UI installer. No telemetry/storage contracts changed in this release. This release retains the prerelease designation and the recorded hardware limitations:

- Service plan was not supplied.
- No physical dish/service outage was induced; service-outage and long-disconnection behavior remain fixture-tested. Safe collector interruption and live desktop restart passed in the historical validation.
- Historical live desktop validation used an isolated installed 1.1.0 runtime with reviewed 1.1.1 source. The 1.2.0 UI uses recorded fixtures; its final installer is verified separately by hosted CI, with no new live-hardware pass claimed.

Source-linked UI research and generated-icon provenance are included in the repository. This is an independent desktop monitoring application.
